# Unified Backtesting Engine

UBE provides a shared input contract and canonical results for backtests using
VectorBT, Backtrader, or NautilusTrader, plus paper-trading interfaces.

The project is pre-release and its public API may change. Start with the
[documentation](docs/index.md) for installation, quickstart, engine behavior,
paper trading, and contributor guidance.

```bash
pip install -e ".[all,dev]"
pytest
```
